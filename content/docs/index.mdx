Home AI is a **family mini-Lovable**: a single Next.js app that lets you connect external services (Google Drive/Calendar/Gmail/Sheets, SMTP/IMAP, Telegram, Notion, Home Assistant, weather) and generate tiny web apps served at `/a/<slug>` and scheduled scripts from a prompt via an LLM.

Everything the family actually uses lives at `/a/<slug>`, generated. The platform provides only three things: a **factory** (prompt → live app), a **trustworthy floor** (storage, execution, versions, access), and **agents** (assistant, MCP, scripts).

## Stack at a glance

- Next.js 16 App Router · TypeScript strict · Tailwind 4
- Drizzle + better-sqlite3 (SQLite only)
- better-auth 1.7.1 · zod · vitest · cron-parser
- googleapis · nodemailer · imapflow · AI SDK v7
